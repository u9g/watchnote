Watchnote in 70 seconds

How a comment in your code turns into a watch on a GitHub issue or pull request, and the email you get when it changes. Turn your sound on.

0:00 / 1:10

Every sound is synthesized live in your browser with the Web Audio API, and every frame is drawn from the playhead time, so you can scrub anywhere. Space plays and pauses; the arrow keys skip 5 seconds. Learn more at github.com/u9g/watchnote.
