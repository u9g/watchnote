A comment on a line of its own that starts with owner/repo#123: and a note watches that issue or PR for as long as the comment is on your repo's default branch. It's the only way to watch something: the note is shown on the item and at the top of its emails, with a link to the line. Delete the comment and the item is no longer watched.
Watchnote scans the repos your GitHub tokens in Settings can read and you can push to, forks aside, again whenever they're pushed to. Files over 1 MB and binary files are skipped.
